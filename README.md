# Tray Monitor

Два компактных графика загрузки **CPU** и **RAM** в системном трее Linux.
Монитор помогает следить за нагрузкой, не открывая отдельное окно.

Приложение написано на Python с PyQt5 и psutil. Основное окружение,
описанное в проекте, — Astra Linux 1.8 с рабочим столом Fly.
Для других окружений Linux необходим системный трей, доступный через Qt.

## Возможности

- Две независимые иконки: загрузка процессора и использование оперативной памяти.
- Обновление раз в секунду, история последних 32 измерений.
- Подсказки с процентами загрузки и объёмом занятой/доступной памяти.
- Подбор фона по цвету панели и контрастного цвета графиков при перерисовке.
- Автозапуск и управление процессом через `install.sh`.
- Выход через контекстное меню любой из иконок.

## Установка и запуск

Требуются Python 3, Bash, `python3-pyqt5` и `python3-psutil`.
Установщик рассчитан на Debian-подобные системы с `apt-get` и `dpkg`.

```bash
git clone https://github.com/ishmyak/trayicon.git
cd trayicon
bash install.sh install
bash install.sh start
```

Команда `install` проверяет пакеты, при необходимости устанавливает их через
`sudo apt-get` и создаёт `~/.config/autostart/tray-monitor.desktop`.
Запускайте установщик от обычного пользователя графической сессии.
Приложение работает прямо из клонированного каталога: после настройки
автозапуска не перемещайте его либо повторите `install` из нового места.

## Управление

| Команда | Действие |
| --- | --- |
| `bash install.sh install` | Проверить зависимости и настроить автозапуск |
| `bash install.sh start` | Запустить монитор |
| `bash install.sh stop` | Остановить монитор |
| `bash install.sh restart` | Перезапустить монитор |
| `bash install.sh status` | Показать состояние процесса и автозапуска |
| `bash install.sh uninstall` | Остановить монитор и удалить автозапуск |

`uninstall` сохраняет исходники и установленные системные пакеты.

Для запуска на переднем плане из графического терминала:

```bash
QT_QPA_PLATFORMTHEME= python3 tray-monitor.py
```

## Если иконки не появились

Посмотрите журнал запуска:

```bash
cat /tmp/tray-monitor.log
```

Нужны работающая графическая сессия и панель с системным треем. Без доступного
трея программа завершится с сообщением об ошибке. В окружениях без трея может
понадобиться его отдельная настройка. Работа под Wayland здесь не подтверждена.

В Fly переменная `QT_QPA_PLATFORMTHEME=fly` может мешать отображению иконок.
Установщик запускает программу с пустым `QT_QPA_PLATFORMTHEME`, чтобы Qt
использовал стандартный механизм трея. При запуске из SSH автоматического
определения графической сессии может оказаться недостаточно; проще запустить
монитор из терминала внутри рабочего стола.

## Структура

- `tray-monitor.py` — сбор измерений, отрисовка графиков и иконки трея.
- `install.sh` — зависимости, автозапуск и управление процессом.

Проект не содержит автоматизированного набора тестов. Отображение иконок
проверяется в целевой графической сессии.
